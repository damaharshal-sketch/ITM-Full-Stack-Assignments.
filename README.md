## Assignment-01 – Student Registration and Result Management System

### Brief Description

**Assignment-01** is a responsive **Student Registration and Result Management System** built with **HTML5, CSS3 and JavaScript**.

The student enters personal details and subject-wise marks. JavaScript validates the data, calculates total marks and percentage, determines the **Pass/Fail** result and displays it on the page without reloading. The student object is converted to JSON and stored in the browser's **Local Storage**.

### Key Concepts Demonstrated

- HTML5 form development
- CSS3 responsive design
- JavaScript form validation
- DOM manipulation
- Total and percentage calculation
- Pass/Fail logic
- JSON object handling
- Browser Local Storage
- Dynamic result display
